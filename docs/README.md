## 已确认的产品规则

- 单租户、自主部署；数据库支持 MySQL 8+，业务表使用单数 snake_case。当前 DDL 使用 CHECK，技术最低版本为 8.0.16。
- `system_setting` 使用受控 KV，以配置名 `name` 为主键，`value` 保存 JSON 类型值；数据访问保留可替换存储接口。
- 首次启动提供安装向导，初始化数据库表、主密钥及创始人。
- 三种系统身份：创始人、管理员、普通用户。管理员权限不再细分，普通用户不能进入控制台，一期不涉及项目权限。
- 创始人是安装时创建的首个管理员，不能删除、禁用、降级或转移身份；资料及密码仅本人修改，部署维护者可通过本地命令恢复密码。
- 管理员可以管理其他管理员；不能禁用、删除或降级自己，不能代改创始人。
- 自主注册安装后默认关闭。管理员开启后，直接创建正常普通用户，无需审批；注册成功自动登录并进入首页。关闭注册不影响已有账号，管理员创建账号不受开关限制。
- **一期不使用邮箱**：没有邮箱字段、邮箱登录、邮件验证、邮件通知、邮件找回或 SMTP 配置。
- 用户逻辑删除后不可从界面恢复；保留用户 ID、用户名及审计关联，用户名不复用；删除凭据、撤销会话、解绑头像。
- 用户名仅管理员可修改；创始人的用户名仅本人可修改。个人设置中的用户名只读。
- 管理员创建账号或重置他人密码后，该用户下次登录必须修改密码；改密前只能使用受限会话。
- 密码使用 bcrypt；新密码最少 8 个 Unicode 码点，最多 72 个 UTF-8 字节，不强制字符类别组合，不截断、不 trim。8 是本项目确认的最小长度。
- 会话默认 30 天，可配置 1–30 天，采用滑动续期：有效业务 API 访问延长到期时间；连续一个窗口无有效访问则失效。禁用、改密、撤销、退出或到期的会话不能被续期恢复。没有前端保活心跳或额外绝对最长登录时限。
- 个人头像支持上传、手动裁剪和移除。
- 控制台包含概览、用户管理、系统设置、基础审计。账号入口位于侧栏底部，主内容顶部用于导航。
- 所有用户登录后进入“首页”；侧栏不显示“个人空间”。普通页面不设置“工作区”按钮，仅控制台保留“返回工作区”。
- 界面统一使用“系统名称”“系统概览”“系统身份”“本系统”；对外 URL 使用“访问地址”。API 字段和配置键中的既有 `site_*`、`site.*` 命名保持稳定。
- API 错误响应采用 `error.details` 数组，支持字段问题与其他结构化原因；本地密码表命名为 `user_password`，领域名为 UserPassword。
- 默认原型采用“柔和微增强”配色与圆脚章鱼 LOGO；保留现有布局和中文阅读尺寸。其他配色与 LOGO 探索稿只作参考。
- 项目、多仓库、团队、自定义项目角色、外部集成、业务定时任务、Graph 工作流和 AI 执行留待后续，不预建这些空模块或表。

## 工程实施约定

| 边界 | 本阶段采用的方向 | 实施时验证 |
| --- | --- | --- |
| 数据访问 | sqlx + MySQL 驱动；goose 迁移；仓储与 UnitOfWork 接口不泄露驱动类型 | MySQL 8.0/8.4 的迁移、扫描、事务与并发契约 |
| 系统设置 | 代码注册表约束 KV，对外仍为明确类型字段；多键视图使用聚合版本 | 设置快照、条件写入与关闭注册的竞争 |
| 本地凭据 | 保留独立 `user_password`，不预建外部登录或 MFA 表 | 常规 DTO 不加载/泄露密码；认证版本统一撤销会话 |
| 密码成本 | bcrypt 初始 cost=12，目标容器测量后确定，不低于 10 | 登录耗时、并发上限与限流 |
| 会话续期 | 创建时保存窗口；每次有效访问在一致事务边界续期并刷新 Cookie，设置修改只影响新会话 | 续期与撤销/清理竞争、持久化 Cookie、浏览器关闭后恢复 |
| 访问地址 | 部署配置指定，安装和系统设置只读展示 | 同源、可信反代、Cookie 与 CSRF |
| 头像 | 草稿上传，保存资料时绑定；服务器重新生成 256×256 PNG | 文件校验、取消编辑、绑定权限和垃圾清理 |

以上是本阶段的实施基线；测量或运行验证发现问题时记录调整依据。仍未安装这些新增依赖，也没有执行真实 MySQL 迁移。

## 原型与正式实现

正式开发以本目录的已确认需求和 UI 设计规范为基线。本机交互原型位于 `.agents/ui/`，仅供交互与视觉参考；原型源码、LOGO 探索稿、截图、配色副本与其他临时文件均不纳入 Git。其 `variants/original/`、`variants/balanced/`、`variants/soft-plus/` 保留历史对照，可能不含最新账号规则。

原型用浏览器演示数据模拟注册、登录、逻辑删除、改密与续期，不连接真实数据库；不会持久保存输入的密码，刷新后演示口令恢复为原型导航中的固定值。正式认证信息不得写入 localStorage。服务器头像规范化、事务、安装所有权与 Cookie 续期需在正式实现中验证。

## 修改与验收约定

- 规则变化时同步领域、API、SQL、UI 规范和默认原型；根目录 [AGENTS.md](../AGENTS.md) 的索引同时维护。
- 架构目录、CLI 和容器示例描述目标状态；当前仓库状态由架构文档单独说明。
- 本阶段完成文档链接、JSON 示例、DDL 静态一致性、JavaScript 语法和默认原型关键交互复核；实库迁移、Cookie、安全与容器验收属于后续实现，不把静态检查写成运行验证。
